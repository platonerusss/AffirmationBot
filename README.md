# Affirmation Bot

Telegram-бот для аффирмаций на Python и aiogram.

Бот позволяет получать случайные аффирмации, добавлять новые фразы, просматривать весь список и включать ежедневную автоматическую отправку в выбранное время.

## Возможности

- получение случайной аффирмации;
- просмотр всех аффирмаций;
- добавление новых аффирмаций;
- кнопки для удобного управления;
- ежедневная отправка аффирмации;
- настройка времени отправки;
- включение и выключение ежедневной рассылки;
- хранение пользовательских настроек в SQLite;
- админ-команда для просмотра пользователей.

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Запустить бота |
| `/help` | Показать помощь |
| `/affirmation` | Получить случайную аффирмацию |
| `/all` | Показать все аффирмации |
| `/add текст` | Добавить новую аффирмацию |
| `/settings` | Открыть настройки |
| `/on` | Включить ежедневную аффирмацию |
| `/off` | Выключить ежедневную аффирмацию |
| `/settime 09:00` | Изменить время ежедневной отправки |

## Админ-команды

| Команда | Описание |
|---|---|
| `/debug_users` | Показать пользователей из базы данных |

Команда `/debug_users` доступна только администратору, чей Telegram ID указан в `.env`.
